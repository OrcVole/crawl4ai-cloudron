# ADR 0002: authentication

Status: accepted, 2026-09-23.

## Context

Crawl4AI is an API that other programs call, like this fleet's TEI, vLLM and Speaches packages.
Upstream refuses to bind anything but loopback unless `CRAWL4AI_API_TOKEN` (or JWT mode) is set,
and its auth gate (`auth_gate.py`) then requires `Authorization: Bearer <token>` on every route
except: the health check, `/token` (which refuses to mint unless a configured API token is
presented), `/` and `/monitor` (redirects), and the static UI shells under `/playground`,
`/dashboard` and `/static`. The shells serve no data; every call they make needs the token.
Verified in gate 0: no token gives 401, the token gives 200.

The field guide's rule for mixed apps is to wall only the human surfaces with a path-scoped
`proxyAuth`. It does not fit here: `proxyAuth` takes one path, there are two UI shells, and both
are inert without the token anyway. Walling the API would break every caller (field guide #8).

## Decision

- **Token only. No `proxyAuth`, no `oidc`, no `optionalSso`.** The manifest declares no SSO
  addon. The recon's "optionalSso" note predates reading the auth gate; with no SSO addon the key
  has nothing to switch.
- `start.sh` seeds a random `CRAWL4AI_API_TOKEN` (`openssl rand -hex 32`) once into
  `/app/data/.secrets/api-token`, mode 0600, and exports it on every boot. It is never
  regenerated. Rotating it is an operator action (delete the file, restart), documented in
  `POSTINSTALL.md`, and it cuts off every client until they are given the new value.
- JWT mode stays off. `/token` therefore answers 403, which is upstream's fail-closed behaviour.
- The post-install message tells the admin where the token is and how to call the API with it.

## Consequences

- One shared secret per install. A caller that needs its own revocable credential should reach
  Crawl4AI through a gateway that issues per-consumer keys (the estate uses agentgateway).
- The token is not data-loss-critical: losing it locks callers out until it is reissued, and no
  stored data is orphaned.
